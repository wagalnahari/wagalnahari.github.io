About n8n.TikTok

An automated video processing platform using FFmpeg for format conversion, resolution optimization, and audio mixing. Process videos for multi-platform distribution including TikTok.

Key Features:

  • Automated video processing with FFmpeg
  • TikTok integration via Content Posting API
  • Secure Login with TikTok OAuth
  • Temporary storage (24-hour auto-deletion)
  • User-controlled permissions only
  • Multi-platform distribution support

TikTok Integration

Products Used:

  • Login Kit
  • Content Posting API

Scope Usage:

  • video.upload: Upload processed videos to user's TikTok account
  • video.publish: Post videos to TikTok feed with user confirmation
  • user.info.basic: Display connected account in dashboard

User Flow:

Upload → FFmpeg processing → Preview → TikTok publish confirmation → Distribution
